# Representation register (genomde2fhir 0.1.0, profile set 2027-ballot)

One entry per open decision of `docs/DISCUSS-TD-2026-10-09.md` (issue numbers in brackets). Where MII has
no conformant element, the converter uses a **local** resource from `de.genomde.mvgs` (`mvgs-ig/`) and
records the value as *preserved*; values with no representation are *dropped* with a reason. Builders
mirror these choices as constants; a ballot outcome changes the entry and the constant, not the design.

ICD-10-GM codes (all branches) go through one helper (`builders/common.icd10gm`): a missing dot after the 3-character category is added, and a trailing multiple-coding mark (`†`/`+`, `*`, `!`) moves to the fhir.de extension `icd-10-gm-mehrfachcodierungs-kennzeichen` on the coding.

Codes that the source carries in the wrong field (e.g. UICC strings in a SNOMED `code`) are accepted with a
warning when unambiguous.
