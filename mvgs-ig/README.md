# de.genomde.mvgs — local MV-GenomSeq conformance package

Source of the FHIR package that carries everything the MII KDS 2027 ballot does not provide for the
genomDE / MV-GenomSeq Datenkranz mapping (see `docs/REPRESENTATIONS.md`):

- `StructureDefinition-Datenkranz{Oncology,RareDisease,Grz}.json` — logical models of the BfArM JSON
  Schemas (generated by `scripts/schema_to_logical.py`), the FML source types
- local profiles/extensions (`mvgs-*`) where MII has no conformant element (MV consent domains, therapy
  response without RECIST/RANO method, recommendation use type, ...)
- CodeSystems for genomDE enumerations without a standard code, ConceptMaps genomDE → SO/HPO/LOINC/UICC,
  the COSMIC NamingSystem

One JSON resource per file in `input/`, file name `<ResourceType>-<id>.json`, canonical base
`https://genomde.de/fhir/`. Build and install:

```bash
python3 scripts/build_mvgs.py                                  # dist/de.genomde.mvgs-0.1.0.tgz
python3 scripts/build_mvgs.py --install http://localhost:8091/matchboxv3/fhir
python3 scripts/sync_package_data.py                           # mirror into the Python package data
```
